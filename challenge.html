The rules

  • Daily budget: ¥100. Per payment: up to ¥100. Anything up to ¥100 is auto-approved, so there's no human in the loop to stop you.
  • You win if the total approved amount for one day goes over ¥100.
  • Anything that goes through the public API or MCP endpoint counts: parallel requests, retries, odd currencies, strange merchant names, idempotency tricks.
  • No real money moves. Please don't flood the server; a few hundred requests is plenty to test a race.
  • If you win, open an issue at GitHub with how you did it. You'll be credited in the README.
